## 0. Get your IDs first (run once)

In Studio SQL editor as `postgres`, run:

```sql
SELECT id AS campus_id FROM public.campuses WHERE name = 'Google';
SELECT id AS faculty_id FROM public.faculties WHERE code = 'GF';
SELECT id AS program_id FROM public.programs WHERE code = 'GP';
```

Copy the 3 UUIDs. In every JSON block below replace:

- `<CAMPUS_ID>` → your Google campus id
- `<FACULTY_ID>` → your GF id
- `<PROGRAM_ID>` → your GP id

Dean has **no** `program_id`. Everyone else includes it.

## 1. How to create each user in Studio

For each user below:

1. Go to **Authentication > Users > Add user > Create new user**.
2. Set **Email** exactly as listed.
3. Set **Password** to `GoogleDev2026!`.
4. Check **Auto Confirm user** (equivalent to `email_confirm: true`).
5. Expand **User Metadata** / **Raw User Meta Data**, paste the JSON block for that user (after replacing IDs).
6. Click **Create user**.
7. Confirm in **Table Editor > public.users** that a row appeared with:
   `email = <that email>`, `campus_id = Google`, `account_status = active`.
   If `public.users` did not auto-create (trigger missing), insert manually in Table Editor with the same `student_id_number / first_name / last_name / email / campus_id / faculty_id / program_id / year` from that user's section, then set `auth_id` to the Auth user id.

Do **NOT** set `app_metadata` role. Leave roles empty — you assign `user_roles` manually later (per your request).

Repeat for all 10. Order does not matter, but do dean/head first so you can spot campus issues early.

## 12. Verify after all 10 (read-only)

```sql
SELECT email, student_id_number, auth_id IS NOT NULL AS linked,
       account_status, year
FROM public.users
WHERE email LIKE 'google.%@dev.com'
ORDER BY email;
-- expect 10 rows, all active, linked=t (or pending if trigger missed, then backfill auth_id by email)

SELECT c.name AS campus, f.code AS faculty, p.code AS program, count(*) AS n
FROM public.users u
LEFT JOIN public.campuses c ON c.id = u.campus_id
LEFT JOIN public.faculties f ON f.id = u.faculty_id
LEFT JOIN public.programs p ON p.id = u.program_id
WHERE u.email LIKE 'google.%@dev.com'
GROUP BY 1,2,3;
-- expect all campus=Google, faculty=GF, program=GP except dean program=null
```

Test login with 1 student + dean before assigning roles. Assign `user_roles` manually afterwards — this guide intentionally creates zero roles.

If any `public.users` row is missing, re-run only Section 3 of `seed_google_developers_fixed.sql` (it links by email and pins Google campus, no roles touched).
